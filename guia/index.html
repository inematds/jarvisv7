JEV Reflex: a novidade desta versão.

O JEV real, via OpenRouter, avalia cinco perguntas em uma chamada: destino, pedido completo, direcionamento ao assistente, necessidade de ação e cobertura das notas.

1. Conecte OpenRouter

Em Configurações → Conexões, configure sua credencial. Usar o JEV consome API e envia o pedido e até seis trechos selecionados.

2. Ative JEV Reflex

Em Preferências, ative “JEV · roteamento Reflex” e salve. Depois faça uma pergunta na conversa.

3. Veja a decisão real

Expanda Reflex no chat: modelo, probabilidades, latência e uso informado. Em falha, o chat continua e sinaliza o fallback local.

As probabilidades não são autorização para agir. O chat continua sem executar email ou agenda. Não prometemos “100 vezes mais rápido”: isso precisa ser medido no seu uso.

Guia de uso · passo a passo

Do clone à primeira memória

Os comandos abaixo são executados no seu terminal. A página do GitHub Pages não hospeda o servidor nem recebe suas credenciais.

1

Instale o projeto

Clone o código público e compile a aplicação.

git clone https://github.com/inematds/jarvisv7.git
cd jarvisv7
npm ci
npm run preflight
npm start
2

Abra seu espaço

Acesse http://127.0.0.1:4700. Escolha um perfil; as notas fictícias são opcionais. Não exponha a porta na rede.

3

Conecte sua conta

Em Configurações → Conexões, use o login do Codex no navegador ou o login já existente. Para Claude, autentique o runtime no terminal e habilite o adaptador pessoal.

claude auth login
4

Escolha modelo e esforço

Em Cérebro, selecione provedor, modelo e esforço. Comece em medium. OpenRouter e Kie usam credenciais próprias salvas apenas nesta instalação.

5

Salve conhecimento e converse

Importe documentos em Conhecimento. Digite “Lembre que…” para salvar uma memória. O botão de provedor no campo de mensagem troca o cérebro da conversa e envia o histórico limitado ao próximo provedor.

6

Use os módulos

Em Preferências, ative mídia, voz, tela ou foco. Na Kie, confirme o consumo antes de gerar. Tela envia apenas um frame explícito junto da pergunta; foco é manual.

7

Faça backup

Pare o servidor com Ctrl+C e copie banco e biblioteca. A exportação JSON da interface não inclui credenciais; a importação web adiciona apenas notas e memórias.

npm run backup -- --stopped
8

Atualize uma instalação

Configure o repositório de releases no ambiente antes de iniciar. Para instalar uma tag futura, pare o servidor, mantenha o Git limpo e use o comando abaixo. v0.1.1 é apenas um exemplo.

export JARVIS_RELEASE_REPO=inematds/jarvisv7
# Instalar uma tag quando ela existir:
npm run update -- v0.1.1 --stopped
