JEV Reflex: what’s new in this version.

Real JEV, via OpenRouter, evaluates five questions in one call: destination, complete request, direction to the assistant, need for action, and coverage of the notes.

1. Connect OpenRouter

In Settings → Connections, configure your credential. Using JEV consumes API credits and sends the request and up to six selected excerpts.

2. Enable JEV Reflex

In Preferences, enable “JEV · Reflex routing” and save. Then ask a question in the chat.

3. See the real decision

Expand Reflex in the chat: model, probabilities, latency, and reported usage. If it fails, the chat continues and indicates the local fallback.

Probabilities are not authorization to act. The chat still doesn't send emails or manage your calendar. We don't promise “100 times faster”: that needs to be measured in your use.

What it is

A personal space to think and create

This page is the public guide. The application runs on your computer, with your own accounts.

🤖 Persistent knowledge

Import MD, TXT, and text-based PDFs. Review notes, save memories, and consult the excerpts used in responses.

User guide · step by step

From clone to first memory

The commands below run in your terminal. The GitHub Pages site does not host the server or receive your credentials.

1

Install the project

Clone the public code and build the application.

git clone https://github.com/inematds/jarvisv7.git
cd jarvisv7
npm ci
npm run preflight
npm start
2

Open your workspace

Go to http://127.0.0.1:4700. Choose a profile; the fictional notes are optional. Don't expose the port to the network.

3

Connect your account

In Settings → Connections, use the Codex login in your browser or your existing login. For Claude, authenticate the runtime in the terminal and enable the personal adapter.

claude auth login
4

Choose model and effort

In Brain, select a provider, model, and effort. Start with medium. OpenRouter and Kie use their own credentials, saved only in this installation.

5

Save knowledge and chat

Import documents into Knowledge. Type “Remember that…” to save a memory. The provider button in the message field switches the conversation’s brain and sends the limited history to the next provider.

6

Use the modules

In Preferences, enable media, voice, screen, or focus. With Kie, confirm the usage before generating. Screen sends only one explicit frame with the question; focus is manual.

7

Back up

Stop the server with Ctrl+C and copy the database and library. The interface’s JSON export does not include credentials; the web import only adds notes and memories.

npm run backup -- --stopped
8

Update an installation

Configure the releases repository in the environment before starting. To install a future tag, stop the server, keep Git clean, and use the command below. v0.1.1 is just an example.

export JARVIS_RELEASE_REPO=inematds/jarvisv7
# Instalar uma tag quando ela existir:
npm run update -- v0.1.1 --stopped
