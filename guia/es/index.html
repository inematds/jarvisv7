JEV Reflex: la novedad de esta versión.

El JEV real, vía OpenRouter, evalúa cinco preguntas en una llamada: destino, solicitud completa, orientación al asistente, necesidad de acción y cobertura de las notas.

1. Conecta OpenRouter

En Configuración → Conexiones, configura tus credenciales. Usar JEV consume API y envía la solicitud y hasta seis fragmentos seleccionados.

2. Activa JEV Reflex

En Preferencias, activa «JEV · enrutamiento Reflex» y guarda. Después, haz una pregunta en la conversación.

3. Mira la decisión real

Expande Reflex en el chat: modelo, probabilidades, latencia y uso informado. Si hay un error, el chat continúa e indica la alternativa local.

Las probabilidades no son autorización para actuar. El chat sigue sin ejecutar acciones de correo electrónico ni calendario. No prometemos «100 veces más rápido»: eso debe medirse en tu uso.

Requisitos previos

Lo esencial para empezar

Node.js 24, npm y Git. Probado en Linux. Codex, Claude y pdftotext son opcionales según las funciones elegidas.

Revisa el entorno

Usa Node 24. Después de instalar las dependencias, el diagnóstico verifica los runtimes sin imprimir credenciales.

# comando
node --version
npm --version
git --version
Guía de uso · paso a paso

Del clon a la primera memoria

Los comandos de abajo se ejecutan en tu terminal. La página de GitHub Pages no aloja el servidor ni recibe tus credenciales.

1

Instala el proyecto

Clona el código público y compila la aplicación.

git clone https://github.com/inematds/jarvisv7.git
cd jarvisv7
npm ci
npm run preflight
npm start
2

Abre tu espacio

Accede a http://127.0.0.1:4700. Elige un perfil; las notas ficticias son opcionales. No expongas el puerto en la red.

3

Conecta tu cuenta

En Configuración → Conexiones, usa el inicio de sesión de Codex en el navegador o el inicio de sesión existente. Para Claude, autentica el entorno de ejecución en la terminal y habilita el adaptador personal.

claude auth login
4

Elige modelo y esfuerzo

En Cerebro, selecciona proveedor, modelo y esfuerzo. Empieza en medium. OpenRouter y Kie usan credenciales propias, guardadas solo en esta instalación.

5

Guarda conocimientos y conversa

Importa documentos en Conocimiento. Escribe “Recuerda que…” para guardar una memoria. El botón del proveedor en el campo de mensaje cambia el cerebro de la conversación y envía el historial limitado al siguiente proveedor.

6

Usa los módulos

En Preferencias, activa medios, voz, pantalla o enfoque. En Kie, confirma el consumo antes de generar. La pantalla envía solo un fotograma explícito junto con la pregunta; el enfoque es manual.

7

Haz una copia de seguridad

Detén el servidor con Ctrl+C y copia la base de datos y la biblioteca. La exportación JSON de la interfaz no incluye credenciales; la importación web solo agrega notas y memorias.

npm run backup -- --stopped
8

Actualiza una instalación

Configura el repositorio de releases en el entorno antes de iniciar. Para instalar una etiqueta futura, detén el servidor, mantén Git limpio y usa el comando de abajo. v0.1.1 es solo un ejemplo.

export JARVIS_RELEASE_REPO=inematds/jarvisv7
# Instalar uma tag quando ela existir:
npm run update -- v0.1.1 --stopped
